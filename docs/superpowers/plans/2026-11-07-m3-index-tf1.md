# M3 step 2 — Generic Index + TF1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 40-Programme TF1 listing with a full, locally stored Index of the 5 TF1 group Chaînes (~2881 Programmes), with finer Genres, a « Policier & Thriller » keyword heuristic and ranked local search.

**Architecture:** A generic `CatalogueIndex` (provider.api) pages a Provider family's whole catalogue (retry, dedupe, short memo) and hands each Chaîne its slice. Storage stays the existing Room listing tables through `CatalogStore` (TTL 12 h, degraded mode, ADR 0002): the Index *is* the full listing. Search becomes local and ranked (`SearchRanking`), shared by `CatalogStore.searchShows` and `SearchFusion.fuse`. M6+ will plug its own page fetcher into the same `CatalogueIndex` later.

**Tech Stack:** Kotlin, Room 2.5.1 (kapt), kotlinx.serialization JSON, OkHttp, JUnit4 + Truth + kotlinx-coroutines-test.

**Spec:** `ROADMAP.md` §M3 (step « Index générique + TF1 »), `SPEC.md` §Provider TF1+ and §Cache, `CONTEXT.md` (Index, Genre, Chaîne), `docs/adr/0002-cache-first-catalog.md`.

## Global Constraints

- Code, comments, tests, commits in English; UI strings in French in `values/strings.xml` (AGENTS.md).
- Zero network in unit tests; parsers tested on trimmed real fixtures in `app/src/test/resources/fixtures/`.
- Index TTL = the listing TTL, `CatalogStore.TTL_MS` (12 h). A failed refresh keeps serving the old Index (ADR 0002).
- TF1 listing query: persisted id `Tf1QueryIds.PROGRAMS` (`483ce0f`), `offset` is a **page index**, page size **500**, filter **omitted** (measured: no filter returns all 4685 items, `data.programs.total`).
- TF1 group Chaînes, keyed on `initialChannel.slug`: `tf1` « TF1 », `tmc` « TMC », `tfx` « TFX », `tf1-series-films` « TF1 Séries Films », `lci` « LCI ». Every other `initialChannel` (arte, novo19, public-senat…) is dropped. Programmes with `replay.total == 0` are dropped.
- Search ranking: title starts with the query, then title contains it; ties broken by `recentEpisodeCount` (TF1 `replayRecent.total`) descending, then input order. Matching uses `Titles.normalize`.
- Build: `./gradlew assembleDebug` · Tests: `./gradlew testDebugUnitTest` (set `JAVA_HOME=C:\Program Files\Android\Android Studio\jre` if unset).
- Room migrations are additive only (Progression and Favoris must survive).

## Review Focus

1. A page fails mid-crawl (503, timeout) → the whole crawl fails, nothing is written, the old Index keeps being served. Test in Task 1 (`failedPageAfterRetriesThrows`) + Task 2 (`failedCrawlKeepsOldListing`).
2. The same slug appears on two pages (offset drift) → it is kept once. Test in Task 1 (`duplicatesAcrossPagesKeptOnce`).
3. 5 TF1 Providers refreshed back to back → only one crawl hits the network. Test in Task 1 (`memoServesSecondCallerWithoutRefetch`).
4. Home with ~2900 TF1 Programmes → every Genre rail is capped, not 1000 cards long. Test in Task 2 (`genreRailsAreCapped`).
5. First launch, Index still empty → TF1 search falls back to remote `searchPrograms`, only once (Chaîne `tf1`), not five times. Test in Task 4 (`emptyIndexFallsBackToRemoteOnlyForTf1`).
