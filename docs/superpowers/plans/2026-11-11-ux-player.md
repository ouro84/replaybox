## Decisions (ambiguities resolved here)

| Topic | Decision |
|---|---|
| Down while the controls are hidden | Shows the controls only, no row focus (spec: keys behave « as when hidden »); a second Down enters the row. |
| Up with the controls shown and no row focus | `SHOW` (keeps them, restarts auto-hide), consumed so focus search never runs. |
| Centre glyph vs Options | Hidden while Options is open (the panel owns the screen, like the prompt). |
| Centre glyph vs buffering ring | One centre slot. Paused → pause glyph (ring suppressed: a paused viewer is not waiting). Playing intent + buffering → ring, as today. Resume prompt → nothing, as today. |
| « Paused » for the glyph | `!playWhenReady` or call-silenced (same meaning as Pause/Lecture today via `PlayerAudio.playing`). Uses `playWhenReady`, not `isPlaying`, so buffering after a resume never shows a pause glyph. |
| Play flash | Only when the glyph goes from paused straight to nothing with `playWhenReady` true; not when Options opens, not into the ring. |
| Timeline touch target | Computed, not fixed: compact scale varies (height 300–479 dp → 0.56–0.89). Target = `ceil(48 / scale)` canvas dp. Pixel 7: scale = 411 / 540 = 0.7611 → 48 / 0.7611 = 63.07 → **64 canvas dp = 64 × 0.7611 = 48.7 real dp**. Tablet / box: 48. |
| Toggle back on within an Épisode | Session kind first (restores a one-off other language), else the stored kind via the apply rule. |
| Audio vs subtitles « other » | `withAudio(OTHER)` keeps clearing the audio preference (unchanged). Subtitles `OTHER` saves « on » and keeps the stored kind (spec). Do not harmonise. |
| Options « Désactivés » chip | A user action: saves « off ». |
| Unused string | `control_pause` is removed once nothing references it (`action_play` stays: Home, Programme page). |
| DESIGN.md | Its « Player » section is updated in the task that changes each behaviour (DESIGN.md is not a restricted doc). |

## Review Focus

1. Box: with the controls shown and no row focus, OK toggles play/pause exactly once and never also clicks a button; after the row had focus and the controls auto-hid, the next reveal has no row focus. (Unit: `stale row focus is ignored once hidden`, Task 2; Bbox checklist, Task 6.)
2. Mobile: a double-tap never also toggles play/pause, and a tap on a control button (or PR A's arrow) never reaches the video layer. (Pixel, Task 7.)
3. A drag that leaves the bar (past either end, or vertically off it) seeks to the clamped position on release; a cancelled drag seeks nothing and auto-hide resumes. (Unit: `x outside the bar clamps`, Task 4; Pixel, Task 7.)
4. Duration unknown (Flux not prepared, `durationMs == 0`): drag and tap on the bar do nothing, never seek to 0. (Unit: `unknown duration maps to nothing`, Task 4.)
5. Stored kind absent from the Flux (hearing impaired stored, only French present): French is applied and the stored kind stays hearing impaired, since automatic application never saves. (Unit: `stored kind missing falls back without losing it`, Task 5; Bbox, Task 6.)
